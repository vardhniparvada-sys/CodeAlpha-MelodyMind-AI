MelodyMind AI – AI Music Composer

MelodyMind AI is an AI-powered music composition application that uses a Long Short-Term Memory (LSTM) deep learning model to generate new musical note sequences from MIDI data.

Features

- AI-powered music composition
- MAESTRO MIDI dataset
- LSTM deep learning architecture
- MIDI note sequence processing
- AI-generated musical notes
- Audio playback with Play/Pause controls
- MIDI music download
- WAV audio download
- Premium dark-themed Streamlit interface
- Trained model integration

Technologies Used

- Python
- Streamlit
- TensorFlow / Keras
- LSTM Neural Network
- MIDI Processing
- MAESTRO Dataset

Model Training

- Dataset: MAESTRO MIDI
- MIDI files preprocessed: 200
- Model: LSTM
- Training epochs: 3
- Generated notes: 300
- Output: MIDI music file

Installation

pip install -r requirements.txt

Run Application

streamlit run app.py
